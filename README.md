# 工程契約與驗收管理（20261127m-lts）

臺北市立東湖國民中學總務處事務組使用的工程管理網站：每個工程依時間分三個階段管理。

1. **技術服務**（委託建築師／技術顧問設計監造）：依工程會「公共工程技術服務契約範本」（115.4.23 版）產生招標版、簽約版 Word；
   依契約第 7、8 條計算服務實施計畫書、設計成果交付與學校審查期限。
2. **施工**（營造廠）：施工廠商、金額、開工日、工期、展延、停復工 → 自動算出預定竣工日。
3. **竣工驗收至保固**：報竣、驗收、結算、付款到保固共 33 項，依序填關鍵日期即可。

網頁放在 GitHub Pages，資料存在 Google 試算表（Apps Script 後端），同仁不需要 Claude 帳號。

## 日常 3 條操作守則

1. **改完就按右上「暫存」**（或 Ctrl+S）。沒暫存的修改會先存成這台裝置的草稿，重開網頁會提示還原到**同一件工程**。
2. **看到「同仁已更新」的提示，先選一個版本再繼續。**選「改用同仁版本」時，你的修改會先自動備份（本機＋下載 JSON），不會遺失。
3. **正式簽約後，到「技術服務履約」勾選「鎖定正式簽約內容快照」**，之後改學校設定不會改動這件工程的期限。

## 功能重點

- **首頁工作台**：問候、每日暖心語錄（可關）、優先處理（逾期＋3 日內，可切換第 4～7 日）、「先記下來」本機記事
  （可匯出、可帶入表件備註）、下班前的小確認（明天與下一個工作日）。下方是「我的工程進度總覽」，
  「表件追蹤／LINE 催辦」收合時不產生內容，展開才計算。
- **中途建檔**：新增工程時選起始階段（契約準備／已有技服／直接施工／驗收／保固追蹤）與技術服務適用性（委託／學校自辦／無委託），
  不必回頭補填前面的欄位。
- **契約 Word**：招標版不寫入乙方與決標金額；成本加公費法、計酬法的服務費用上限只用「招標前核定上限」。
  保險（雇主意外險、專業責任險終點）與契約型態有互斥時，不能下載並說明原因。
- **期限**：嚴格日期（2026-02-30 不計算）、臺北時區；保固年數須能換算整月；預計保固會勘日只是安排，不改期滿日；
  日曆天末日遇假日可選順延／不順延；期限跨入「已維護假日資料年度」以外的年度時標示「日期為試算」。
- **初驗**：可選「依金額建議／須初驗／免初驗」（2,000 萬元為校內初驗建議門檻）；已填驗收合格日而沒有初驗日期時視為免初驗，不卡結案。
- **停復工**：已復工且「核定淨增日數」者加到預定竣工日；停工中（尚未復工）標示「原期限待核對」，不列入正式逾期。
- **同仁共用**：共用 Google 日曆、工程文件資料夾、每週一週報；同步失敗時頁首出現「日曆未同步（點此重試）」。
- **安全**：單一存取碼（至少 12 字元）只放在 POST 內容；左下「安全登出並清除本機資料」。
